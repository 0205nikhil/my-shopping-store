# 🛒 My Shopping Store

A simple e-commerce shopping website built with **HTML, CSS, and JavaScript**.

This project is also used as a hands-on **DevOps learning project** to practice:

- Git
- GitHub
- Docker
- Docker Hub
- Jenkins
- CI/CD
- Kubernetes
- AWS

---

## 📌 Project Overview

This is a simple shopping website inspired by modern e-commerce websites.

The application contains:

- Product listing
- Product images
- Product prices
- Product ratings
- Search functionality
- Category filtering
- Add to Cart functionality
- Responsive design

The main purpose of this project is to learn how to take a simple application and deploy it using modern DevOps tools.
